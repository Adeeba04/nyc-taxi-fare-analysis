# nyc-taxi-fare-analysis
This project conducts an end-to-end exploratory data analysis (EDA) and data hygiene assessment on 22,699 trip records from the New York City Taxi & Limousine Commission (NYC TLC). Using Python within the **PACE** (Plan, Analyze, Construct, Execute) framework, the analysis investigates revenue drivers, payment distributions, vendor pricing parity, and driver gratuity behavior. 

The primary deliverable is an actionable data evaluation that establishes core predictors for predictive fare modeling, identifies system-level tracking constraints (such as unrecorded cash gratuities), and isolates transaction anomalies (refunds, disputes, and zero-distance charges).
